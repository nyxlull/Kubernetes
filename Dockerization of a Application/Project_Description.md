🐳 Inspire API (Python) – Dockerized REST API

A simple Flask-based REST API that returns a random inspirational quote when you call the `/api/quote` endpoint.

🛠 **Note:** I did not create this application from scratch. The purpose of this project is to demonstrate my ability to Dockerize a Python application, follow best practices in containerization, and use DockerHub for image sharing and deployment.

---

## 📌 Project Goals

- Showcase a clean and minimal Python/Flask app for containerization.
- Dockerize the app using multi-stage builds.
- Push and pull the Docker image using DockerHub. (T0 BE COMPLETED)
- Demonstrate understanding of Docker architecture and image optimization.

---

## ⚙️ Tech Stack

- **Python 3.11**
- **Flask**
- **Docker (Multi-stage Build)**
- **DockerHub**

---

## 🧠 Features

- Lightweight REST API
- Returns a random inspirational quote
- Two routes:
  - `/` — Welcome message
  - `/api/quote` — JSON with a quote
